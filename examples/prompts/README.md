# Prompt examples

These requests describe small applications and their verification checks.
They are optional examples. They do not require a particular model or editor.

[counter.md](counter.md) targets `maint/1.x`. Compare the generated application
with [iex_counter](../iex_counter) on that branch. Use the
[community guide](../../guides/user/12-community.md) to share or contribute a
request with a verified example.

For v2 work, use `next/v2` and its application contract. Do not combine v1
render trees with v2 frames or pure widgets.
