# Prompt examples

These requests describe small applications and their verification checks.
They are optional examples. They do not require a particular model or editor.

[counter.md](counter.md) targets `next/v2`. Compare the generated application
with [iex_counter](../iex_counter), which runs on the same branch. Use the
[community guide](../../guides/community.md) to share a result or contribute
another request with a verified example.

For v1 work, use `maint/1.x` and its application contract. Do not combine v1
render trees with v2 frames or pure widgets.
