# TermUI guides

This source tree contains `2.0.0-rc.2`, the second v2 release candidate. It is
not the final 2.0 release. Read the guides by task rather than by module name.

| Task | Read |
| --- | --- |
| Run a first application | [Getting started](getting-started.md), then [example lessons](examples.md) |
| Understand ownership and effects | [Architecture](architecture.md), [pure widgets](widgets.md) |
| Compose input, forms, tables, and streams | [Runnable widget recipes](widget-recipes.md) |
| Add input, selection, or rich content | [Interaction](interaction.md), [Markdown and diffs](markdown-and-diffs.md) |
| Select or implement a host | [Backend contract](backend.md), [browser host](web.md), [optional terminal sessions](terminal-session.md) |
| Test behavior and cleanup | [Testing](testing.md), [physical terminal checks](terminal-checks.md) |
| Move a v1 application | [Migration](migration-2.0.md), [widget parity](widget-parity.md), [feature parity](feature-parity.md), [deferred features](removed-and-deferred.md) |
| Maintain or build the package | [Repository layout](repository-layout.md), [package quality](package-quality.md), [Linux builds](linux-releases.md), [publishing](publishing.md) |
| Find support | [Community](community.md) |

Use module documentation for full function and option references. Maintainer
plans and recorded fixes belong in `docs`; they are not user instructions or
proof that a package has been published.
